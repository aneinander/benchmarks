# bench-standard

Benchmark your LLM server the way everyone in the group does. One file:

```sh
pip install git+https://github.com/GGZ14/BetterBench   # BetterBench 0.6.1 or newer
curl -O https://git.linxweiler.xyz/miga/benchmarks/raw/branch/main/bench.sh && chmod +x bench.sh
./bench.sh --help
```

The models to use, and a step-by-step guide you can hand to a coding agent:
[`AGENTS.md`](AGENTS.md).
